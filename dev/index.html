CertifiedRecords.DataverseFile — Type
DataverseFile

One file of a dataset version, as the native API lists it: the datafile id, the label (its name in the dataset), the directory (directoryLabel, empty if none), the size in bytes, the checksum checksum_type and checksum, and whether Dataverse ingested it as tabular, in which case checksum is that of the file as uploaded.

CertifiedRecords.Upper — Type
Upper(x)

Marks x as an upper bound in a row passed to append_record, which then writes it with fmt_upper. Intervals are upper bounds through their supremum with no marking, by the extensions for IntervalArithmetic and Arblib.

CertifiedRecords.dataverse_add — Method
dataverse_add(doi, path; directory = "", description = "", server, token_file) -> DataverseFile

Add the file at path to the draft of dataset doi, under directory in the dataset, with tabular ingest skipped so that it is stored byte for byte; the checksum Dataverse reports is compared with the local one. Creates a draft version if the dataset has none. Nothing is published. The size Dataverse reports is compared with the local one as well.

Run against dataverse.harvard.edu on 2026-11-20 (49 files, directory labels of two levels, no tabular ingest), and exercised by the token-gated live test.

CertifiedRecords.dataverse_download — Method
dataverse_download(f::DataverseFile, dest; server, token_file = nothing) -> dest

Download f to the path dest and verify its size and checksum against the listing; an ingested tabular file is downloaded in its original uploaded form (format=original), the one the checksum is of. The download goes to a temporary file beside dest, which is moved onto dest only once it verifies; if the transfer fails or the file does not verify, the temporary file is removed, dest is left as it was, and an error is raised.

CertifiedRecords.dataverse_files — Method
dataverse_files(doi; version = ":latest-published", server, token_file = nothing)

The files of one version of the dataset doi (e.g. "doi:10.7910/DVN/XXXXXX"), as DataverseFiles. version is ":latest-published", ":latest" (the draft if there is one), ":draft" or a number such as "1.0"; a draft needs a token_file, e.g. default_token_file().

CertifiedRecords.dataverse_replace — Method
dataverse_replace(f::DataverseFile, path; description = "", server, token_file) -> DataverseFile

Replace the deposited file f with the file at path, in the draft. Dataverse does not carry the directory and description of f over to the replacement (API Guide, "Replacing Files"); f.directory is passed as directoryLabel in the request, which the Guide documents for adding a file but not for replacing one, so whether it is applied has to be checked on the installation. The checksum is compared as in dataverse_add. Nothing is published. Not yet run against an installation, as dataverse_add.

CertifiedRecords.default_token_file — Method
default_token_file() -> String

The path of the API token file: $DATAVERSE_TOKEN_FILE if set, otherwise ~/.config/wtools/dataverse-token, the file wnew --dataverse reads. Every function of this package takes the token as the path of such a file (token_file), never as a string: the token is read only to build the request header, so it is not held by the caller and cannot be printed or logged from there. A token is specific to one installation.

CertifiedRecords.fmt_upper — Method
fmt_upper(x; digits = 7) -> String

The least decimal of digits significant digits that is at least the bound, written as d.ddd…e±XX. The bound b is converted exactly to a rational, e = ⌊log₁₀|b|⌋ is found exactly, and the decimal is $⌈b\,10^{d-1-e}⌉\,10^{e-d+1}$, $d$ = digits, with a carry into the next decade when the ceiling reaches $10^d$; so it exceeds the bound by less than one unit in its last digit. For an interval, b is its supremum. Anything else is written by string.

CertifiedRecords.latest_record — Method
latest_record(dir, prefix; host = gethostname()) -> path

The record dir/prefix.<commit>.<host>.tsv written last, by modification time, among those of every commit, where <commit> is the short hash run_header records (or unknown); an error if there is none. A driver writes one record per commit, so a reader of another driver's results should name the file this returns.

CertifiedRecords.read_double — Method
read_double(digits) -> Float64

A double a record holds, written in full: the decimal write_endpoint writes for it at 53 bits, the one string writes, or a decimal exactly equal to it. An error if the decimal is not a double, so that a value rounded on the way into a record is not read as though it had not been. Inf, -Inf and NaN are read as themselves.

CertifiedRecords.records — Method
records(dir, prefix; host = gethostname()) -> Vector{String}

Every record dir/prefix.<commit>.<host>.tsv, one per commit, oldest first by modification time, <commit> as in latest_record; empty if there is none. A reader that needs the rows of every run, and not only those of the last commit, reads them in this order and lets a later row replace an earlier one with the same key.

CertifiedRecords.run_header — Method
run_header(mod, script; params...) -> String

The header a driver writes above its rows, as # lines: the script, the machine, the time, the commit of the package mod and whether its working tree was clean, the Julia version and the thread count, then the parameters of the run. A run whose commit is not recorded cannot be repeated, and a run from a dirty tree says so.

mod is the package whose code produced the numbers, e.g. DiffusionExperiments; the commit is read with git -C pkgdir(mod), and unknown is written if that fails.

CertifiedRecords.save_environment — Method
save_environment(record) -> String

Copy the Manifest.toml of the active project next to record, as <record without .tsv>.<time>.Manifest.toml, and return its file name, for a driver to write in a column of the rows it appends. A dependency the Manifest gives by path (a working copy, which the Manifest alone cannot reconstruct) is listed below the copy, as a TOML comment, with the commit its checkout is at and whether its tracked files differ from it:

# path RigorousInvariantMeasures /home/isaia/Code/RigorousInvariantMeasures.jl 87aed84 clean

so that every row names the exact versions of every package that produced it. An error if the active project has no Manifest.

CertifiedRecords.summary_row — Method
summary_row(quantity, kind, value) -> Vector{Any}

The columns of the record of the numbers a text quotes, and one row of it. kind says what the number is: upper, an upper bound, written as upper_bound of the value in its own precision (a double for an Arblib ball or an interval); lower, a lower bound, and exact, a value or a choice; lo and hi, an end of an enclosure; count, an integer. Every float is written in full, with its precision in bits.

CertifiedRecords.upper_bound — Method
upper_bound(x, T = Float64) -> T

An upper bound on x in the floating-point type T: a real rounded up to T; an interval of IntervalArithmetic through its supremum and an Arblib ball through the upper end of the interval enclosing it, by the extensions. Inf and NaN stay what they are.

CertifiedRecords.write_endpoint — Method
write_endpoint(x::AbstractFloat) -> (digits, bits)

An interval endpoint as the shortest decimal that gives x back at its own precision, and that precision. read_endpoint inverts it exactly; reading the decimal at any other precision does not, because the shortest decimal round-trips only at the precision it was written for. A subnormal x has fewer significant bits than its type, and the shortest decimal that gives it back in that type is read at its precision as a different number (5.0e-324 against the double 4.94e-324), so it is written as the shortest decimal of the same number as a BigFloat of that precision.

source
CertifiedRecords.write_interval — Method
write_interval(lo, hi) -> (lo_digits, hi_digits, bits)
write_interval(x) -> (lo_digits, hi_digits, bits)

The two ends of an enclosure written by write_endpoint, and their common precision, for three columns of a record. An interval of IntervalArithmetic is written through its infimum and supremum and an Arblib ball through the interval enclosing it, rounded outward at the precision of the ball, by the extensions. A pair of NaN, which a driver writes where it has no enclosure, is accepted; an inverted pair is not.

source
CertifiedRecords.write_upper — Method
write_upper(x, T = Float64) -> (digits, bits)

An upper bound written exactly: upper_bound of x in T, written by write_endpoint, so that read_upper gives back that bound and not a decimal near it. fmt_upper prints seven digits for a person to read; this is what a driver writes where the bound will be read back.
